# Approved mockups (Nov 17, 2026)

Source files of the clickable mockups RJ approved. Live version: https://claude.ai/artifact/VqfNTXgLjGRtLZA3HUCUmX

- `Main.dc.html`: the app (Plan, Live, My Trips, Family, ☰ Menu). Sample data only.
- `Onboarding.dc.html`: first-open setup (welcome, safety tick box, guided chat, your boat with photo, limits, route, who follows you, permissions, first GO answer).

The `.dc.html` files are Claude Design artboards (HTML with a small templating layer); read them for layout, copy, states and flow. They are the approved direction, not pixel-perfect specs.

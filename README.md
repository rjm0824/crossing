# Crossing · Goof n' Off

A one-page, phone-first dashboard for the Palm Beach → Abaco crossing.

- Go / crossable / no-go call scored against RJ's limits (under 3 ft go, 3–4 ft crossable, over 4 ft no, no north wind against the Gulf Stream), with the best departure time.
- Route map (Palm Beach Inlet → Memory Rock → Little Bahama Bank → Green Turtle) with animated radar and sea marks.
- Hour-by-hour seas and wind at each route point at the hour the boat passes it.
- Inside Sea of Abaco chop estimate and a Whale Cay passage check.
- Palm Beach tides (NOAA), a rough Green Turtle tide, arrival time, fuel and sunrise.
- GPX route download for the Garmin.
- Boat position for family (rounded to about a mile, stops near Green Turtle). Captain mode: open the page with `#captain`.

Data: Open-Meteo (marine + weather), NOAA tides, RainViewer radar, CARTO/OpenStreetMap and OpenSeaMap tiles. No keys. Static site on GitHub Pages.

**Drafts only.** Waypoints are approximate and the call is a model-based draft. Check NWS, NHC and your charts, then make the call yourself.
